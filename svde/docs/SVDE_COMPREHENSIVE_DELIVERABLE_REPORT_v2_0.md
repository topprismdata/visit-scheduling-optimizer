## 2. 第一部分：快消现场世界模型设计 (v2.0 提案) 与五大业务真相

*(注：本部分为领域本体升级 v2.0 的 DCR 设计草案，当前代码库底层实现仍为 v0.3 的 19 个核心对象)*

```
[连锁大客户总部]
AccountHierarchy (Woodburn 2002/2014)
       │ (1:N 统管与协议继承)
       ▼
  Customer (门店) <────── SupplyNodeLink (Shanahan 2007/2019) ─── [18 个专属大仓配货协同]
       │
       ▼ (驱动拜访)
  VisitDemand <────────── ProductLineScope (Johnston & Marshall 2016) ─── [皇家/源悦多品类]
       │
       ▼ (现场执行)
VisitOccurrence <──────── InStoreActionTaxonomy (Zoltners 2006) ─── [开新/缺货/防损/陈列/订单]
       │
       ▼ (事实反哺)
ExecutionHistory <─────── MerchandisingCompliance (Anderson & Stern 2004) ─── [合同陈列达标率核销]
```

### 1. 权力与大盘中枢（`AccountHierarchy`）
- **数据事实**: **爱婴室（33.5%）+ 孩子王（16.1%）+ 婴知岛（11.6%）三大母婴连锁独占了 61.2% 的大盘**。
- **业务本质**: 快消销售不是扫街，而是对重点连锁系统的子店进行网格化履约。拜访政策首先基于 KA 总部协议下发。

### 2. 品牌线分化作战（`ProductLineScope`）
- **数据事实**: 皇家美素（`Prestige`，2,567次）以【效期防损】与【陈列核销】为主；源悦+皇家（`Natura + Prestige`，2,735次）【开新派样】激增至 241 次，【缺货补货】492 次。
- **业务本质**: 成熟现金牛爆品（皇家）主攻**保排面与防断货**；战略新品（源悦）主攻**妈妈粉试饮拉新与终端铺货**。

### 3. 供应链配货时钟（`SupplyNodeLink`）
- **数据事实**: 爱婴室嘉善大仓（专供74店）、孩子王南京总仓（专供31店）、浒关DC仓等 8 个大仓掌控了 66% 门店的供货脉搏。
- **业务本质**: 快消门店缺货补货受制于大仓配货周期。将巡店与大仓送达窗口对齐，是消除“盲目催单”与“延误上架”的根本杠杆。

### 4. 合同陈列真金白银核销（`MerchandisingCompliance`）
- **数据事实**: Key 级别大店中 **22%（942次拜访）签订了明确的陈列协议**，合同目标排面均值 58.0 个，实际达标 66.0 个，**达成率 117.9%**。
- **业务本质**: 代表进店首要任务是核销昂贵的端架进场费投资，防止竞品侵蚀核心排面。

### 5. 产能与在店时长合成（`InStoreActionTaxonomy`）
- **数据事实**: 五大纯动作耗时基线清晰呈现：
  - **效期防损**（45.7 min，奶粉防损红线）
  - **缺货补货**（54.0 min）
  - **店长客情**（54.5 min）
  - **开新派样**（55.0 min）
  - **陈列核销**（61.5 min，搭地堆调端架最耗时）
- **业务本质**: 在店服务时长不是常量，而是由**现场动作组合显式合成的业务产物**。
