## 1. 业务问题

"3 次/月" 是"至少 3 次"、"至多 3 次"、还是"3±1 次"？当月拜访 2 次或 4 次是否违规？

## 2. 选定规则 (rule)

"3 次/月" = **下限 3 次 + 上限 5 次**。月内实际拜访次数 2 次 → 违反；6 次 → 违反；3-5 次 → 合规。

## 3. 适用范围 (scope)

所有 tier=A 或 B 门店。

## 4. 生效时间 (effective_time)

2026-09-01 生效。

## 5. 责任人 (owner)

业务方: 销售运营经理。

## 6. 例外条件 (exceptions)

- 当月含重大促销（618 / 双11 / 国庆）: 上限可放宽至 7 次
- 春节当月: 下限可放宽至 2 次
- 客户主动申请暂停: 例外 1 个月

## 7. 违反处理 (violation_handling)

- **WARNING**: 实际次数低于下限 1 次
- **CRITICAL_INCIDENT**: 实际次数为 0，或超过上限 ≥2 次
