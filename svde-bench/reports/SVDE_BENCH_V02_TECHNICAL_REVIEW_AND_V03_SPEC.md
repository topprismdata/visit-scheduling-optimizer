## 3. Unverified Hypotheses & Known Boundaries (What Remains to Be Proven)

Before claiming general decision intelligence evaluation, the following research boundaries are formally recorded:

1. **H1: Cross-Domain Pattern Generalization**  
   *Current state:* Verified in `Delivery` (D01–D10) and partially tested on single `Visit` fixture.  
   *Unverified:* Whether identical Decision Compiler & Pattern Synthesis paradigms scale uniformly to **Warehouse Slotting / Congestion** and **Channel / Dealer Strategy**.
2. **H2: Out-of-Domain Memory Transfer (Cross-Case Generalization)**  
   *Current state:* Memory benefit verified within identical case sequences ($D09_{t1} \rightarrow D09_{t2}$).  
   *Unverified:* Whether an episodic memory formed at Facility A safely transfers to Facility B without negative transfer.
3. **H3: Adversarial False-Memory Resistance (Negative Transfer Defense)**  
   *Current state:* Stale memories generated by agents are rejected during admission.  
   *Unverified:* Behavior when an external attacker injects a syntactically valid but strategically adversarial memory patch into the store.
4. **H4: Real-Time Contextual Memory Override**  
   *Current state:* Episodic memory guides static/replanning dispatch.  
   *Unverified:* Dynamic conflict resolution when real-time telemetry strictly contradicts a promoted long-term policy recommendation.
