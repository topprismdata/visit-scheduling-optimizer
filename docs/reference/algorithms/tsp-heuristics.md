# 0. 30 秒理解

TSP Heuristics 解决的问题：

> 给定当天门店集合，在极短时间内生成一条质量尚可的开放路径。

它不追求证明最优。

它追求：

    速度

    +

    可重复

    +

    足够好的路线估计

# 2. 它解决什么

输入：

    当天门店集合

    +

    距离矩阵

输出：

    开放路径

    A → B → C → D

不要求：

    D → Depot

即：

    Open Hamiltonian Path

------------------------------------------------------------------------

# 3. 核心机制

## 3.1 最近邻（NN）

流程：

    选择起点

    ↓

    每一步选择最近未访问门店

    ↓

    形成初始链

当前确定性规则：

    距离平局

    ↓

    store id 升序

保证：

    same input

    ↓

    same route

------------------------------------------------------------------------

## 3.2 2-opt

基于：

Croes (1958)

思想：

删除：

    (a,b)
    (c,d)

替换：

    (a,c)
    (b,d)

并反转中间片段。

目标：

消除路线交叉。

------------------------------------------------------------------------

## 3.3 nn2opt_open

组合：

    NN

    +

    2-opt

    =

    快速路线

------------------------------------------------------------------------

# 4. Multi-start

单起点 NN：

容易受到：

    起点选择

影响。

因此：

    多个起点

    ↓

    重复 NN+2opt

    ↓

    取最短

这是 SDR Route Pool 思想的轻量版本。

质量：

    单起 nn2opt

    <

    multistart nn2opt

    <

    CP-SAT

速度：

    反向排列

------------------------------------------------------------------------

# 5. 确定性设计

当前：

- 纯函数；
- 无求解器调用；
- 平局按 id 排序。

因此：

适合作为：

- benchmark baseline；
- 快速估价器；
- 上层搜索辅助。

------------------------------------------------------------------------

# 6. 非对称距离矩阵风险

生产矩阵：

由于：

- OSM 单行道；
- 方向限制；

可能：

\[ D(i,j)D(j,i) \]

当前 2-opt 传统交换判据隐含：

    对称距离假设

因此：

在非对称矩阵：

    接受判断可能失真

影响：

    搜索效率

不影响：

    最终 route km

    （按有向矩阵重新计算）

------------------------------------------------------------------------

# 7. 修复方向

方案：

## Directed-safe 2-opt

每次：

    完整重算段内有向成本

优点：

正确。

代价：

计算增加。

------------------------------------------------------------------------

## Relocate 类算子

通过：

    移动节点位置

避免对称假设。

------------------------------------------------------------------------

# 8. 复杂度

NN：

\[ O(n^2) \]

2-opt：

每轮：

\[ O(n^2) \]

n=35：

    毫秒级

因此：

适合作为：

    实时估价器

------------------------------------------------------------------------

# 9. 与精确 TSP 的关系

NN+2opt：

回答：

> 快速得到一个好路线。

CP-SAT：

回答：

> 这个路线距离离理论最优还有多少。

实测：

    nn2opt

    约 +11~16% km

    vs CP-SAT

因此：

两者职责不同：

    快

    vs

    准

------------------------------------------------------------------------
