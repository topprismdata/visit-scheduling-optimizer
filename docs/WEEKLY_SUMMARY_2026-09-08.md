## 三、语义层：正确的定位（本轮最重要认知）

**语义层 = 业务需求 → 引擎约束的翻译器**，不是引擎的重写。

```
业务系统 (SRP 表 / 客户档案)
    │ Stage 1: 频次需求 {horizon, visits} + 走廊 [min, max] + 目标 min km
    ▼
R2-ALNS (已验证引擎, 不改动核心逻辑)
    │ 加载频次约束 → 合同同构搜索 → 精确重排
    ▼
方案 + 五道闸验证
```

**本周的错误**：我试图用"频次展开 → 确定性铺排"**替换** R2-ALNS 的规划逻辑——结果丢掉了 ALNS 的全部优化能力（地理感知、走廊均衡、相位探索），产出 km=472（劣于人类 326）。

**正确做法**：语义层输出**约束**（每店每 horizon 来 visits 次），R2-ALNS 在约束内**自由规划**（相位/星期几/路线全部是决策变量）。初始解用原计划（地理感知），ALNS 在此基础上改进。
