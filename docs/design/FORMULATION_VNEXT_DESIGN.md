# VisitModel Formulation vNext 设计：固定 (店,日期) 行空间的 Contract-SP 重构

> **状态**：草稿 v0.3 · 2026-09-07（待评审；通过后转实施计划）。
> **版本记录**：v0.1 初稿 → v0.2（三遍自检：§3.4 LP 关系方向纠错、rc 符号不变量测试、风险表重建）→ **v0.3（2026-09-07 外部评审修订，8 项）**：R1 定价符号按代数定义修正（删"以求解器为准"搪塞）；R2 补正频次星期几域 W_c⁺（零频次 z 使整店消失的反例封堵）；R3 node_valid_lb 资格条件全集化（LP OPTIMAL + 快照一致 + 全日期定价 + 容差内非负 + 恢复变量清零）；R4 CG 收敛测试改全列枚举真值对照；R5 撤销"逐线相等"硬闸（改冻结池等价 + 端到端分报告）；R6 反例更换为已验证合法反例、严格性改为实例相关；R7 字段名对齐协议（`rmp_lp_value`/`certified_global_lb`）；R8 归因软化（重构依据三分，历史证书逐项审计）。

## 1. 背景

### 1.1 现行 master（v1，`formulation.py`）

```
min  Σ_r km_r x_r
s.t. (1) Σ_{r∈R_d} x_r = 1                 ∀d          对偶 π_d
     (2) Σ_w z_cw = 1                       ∀c
     (3) Σ_{r∋c} x_r = Σ_w f_cw z_cw        ∀c          对偶 μ_c
     (4) x_r ≤ z_{c,wd(r)}                  ∀r, ∀c∈r    ← 列特定行（问题所在）
     x ∈ [0,1], z ∈ [0,1]
```

### 1.2 缺口（按已证/待审分列，2026-09-07 评审 R8 归因修正）

**已证缺口（重构的直接依据）**：
1. **行空间随列增长**：约束 (4) 对每条池内列、每家列内店各一条——新列进来同时新增 |route| 条行，不满足经典列生成"对偶行空间固定、列空间动态扩展"的前提。
2. **定价 rc 不完整**：`rc = km − Σ μ_c − π_d` 未计入 (4) 的对偶贡献，不是现行 master 中该列的完整 reduced cost。
3. **未证 LP 值被用于剪枝与证书**：启发式定价停住、精确定价未完成时，受限池 LP 值曾被当作"子树真下界"使用（bp 现行实现；P0-2 已修文档与语义，代码门控随本重构落地）。

**待逐项审计（不预设结论）**：历史 BP 证书是否可经"新增绑定行对偶置 0 + 校验全部对偶条件"延拓为有效界——可行则个别历史证书可追认，不可行则如实降级。逐项审计在实施阶段执行；无论审计结果如何，**历史可行日程的里程数字与证明资格继续分别处理**。

### 1.3 影响面

| 受影响 | 影响 | 不受影响 |
|---|---|---|
| `sp_solve_lp`（CG 收敛语义与下界有效性） | 依赖 v1 行空间假设的收敛/界主张需按 v2 重述 | **SP-IP 终闸（CP-SAT）解的正确性**——全行显式建模、精确求解，历史 km 数字（−13.03% 等）有效 |
| `price_columns`（rc 方向与奖励来源） | 定价奖励改为逐 (店,日期) β | 各引擎候选生成（列来源合法性与本重构正交） |
| `branch_and_price`（节点 LP、分支、剪枝、证书） | 下界资格条件全集化（R3）、分支落 y 变量 | 引擎接口契约（LineData/D/AlgoResult） |

## 2. 目标与非目标

**目标**：
- G1 固定行空间：新列只给**既有行**加系数，CG 回归标准 fixed-row 形态。
- G2 合法域内生化：合同/相位合法性由变量域表达（非法 (店,日期) 的 y 上界固定为 0），不再依赖池预过滤保证正确性。
- G3 定价 rc 按代数定义与 master 严格闭合（含绑定行对偶贡献，符号由公式确定而非"以求解器为准"）。
- G4 bp 分支直接落在 y 空间；节点下界资格条件全集化（R3），`rmp_lp_value` / `node_valid_lb` / `certified_global_lb` 三分并与研究协议字段对齐（R7）。
- G5 验收测试按评审建议重建（§5）：全列枚举真值对照、同冻结核、分类状态、端到端分报告——不设无依据的逐线相等硬闸。

**非目标**：不实现 ESPPRC 精确定价本体（另立计划）；不改引擎输入输出契约；不回填历史实验；不重写搜索器。

## 3. v2 数学设计

### 3.1 变量

| 变量 | 域 | 说明 |
|---|---|---|
| `x_r` | [0,1]（LP）/ {0,1}（IP） | 候选列选择，r ∈ 池 |
| `y_cd` | [0,1]（LP）/ {0,1}（IP）；**UB=0 若 (c,d) 合同非法** | 店-日访问指示：店 c 在日期 d 被访。全 (c,d) 网格创建，非法格用上界 0 封死 |
| `z_cw` | [0,1]，**仅定义于 W_c⁺ = {w : f_cw > 0}** | 星期几选择器。零频次星期几不建变量——否则 z 选到 f=0 的 w 可令整店消失（R2 反例）。W_c⁺ 为空 ⇒ 返回明确不可行状态，不得静默跳过 |

`f_cw` 定义必须与同一版本的合同合法日期集一致（`contract_slot_dates(κ, φ, wd slots)` 的计数）。

### 3.2 行（全部固定，定义在实例域上，与池无关）

```
(A) 日期覆盖      Σ_{r∈R_d} x_r = 1                 ∀d          对偶 π_d
(B) 链接定义      y_cd − Σ_{r∈R_d: c∈r} x_r = 0      ∀(c,d)      对偶 β_cd
(C) 星期几绑定    y_cd ≤ z_{c,wd(d)}                 ∀(c,d)      对偶 γ_cd
(D) 合同频次      Σ_d y_cd = Σ_w f_cw · z_cw         ∀c          对偶 μ_c
(E) 唯一星期几    Σ_w z_cw = 1                       ∀c
(F) 合法域        y_cd ∈ [0, UB_cd],  UB_cd = 0 若 (c,d) 非法
```

新列 r 进入时只做一件事：往 (A)(B) 的**既有行**上加系数。行数 = |D| + 2·|C|·|D| + 2·|C|，恒定。

### 3.3 定价（CG）

**rc 公式（按代数定义，R1 修正）**：链接行 (B) 写为 `y_cd − Σ_{r∈R_d:c∈r} x_r = 0`，列 r 在该行的系数为 **−1**，故

```
rc(r@d) = km_r − π_d + Σ_{c∈r} β_cd        （等价地：访问奖励 reward_cd = −β_cd）
```

- 不设"符号以求解器为准"的搪塞——行方向由本公式的建模选择固定。
- **最优性条件含上界（评审 R1）**：变量处于上界（x_r=1、y=1）时 rc ≤ 0 合法；处于下界（0）时 rc ≥ 0 合法；基变量 rc = 0。守卫测试必须按变量状态分类断言，不得无条件要求全部 rc ≥ 0。
- 验证方法：先逐列比较手算 rc 与求解器 `reduced_cost()`；再用微型全列枚举核对未入池列的最小 rc 真值。

定价子问题结构：当日合法店集上"选 Σ 最大化 Σ reward_cd、路径长最小"，规模 ≤max_daily、≥min_daily——现有贪心启发式与 CP-SAT 奖收集兜底平移，奖励换 reward_cd。

### 3.4 与 v1 的关系（R6 修正）

- **LP 强化方向**：相同合法列域、相同正频次开放域与成本下，v2 在 (x,z) 投影上的 LP 可行域**包含于** v1，最优值**不低于** v1。**是否严格依实例与列池而定，不写普遍严格包含。**
- **已验证严格强化反例**（替换 v0.2 的无效反例——原例 x₁=x₂ 同日违反"每日恰选一列"，作废）：三家周访店 c/a/b，两周各周一/周二共 4 日，走廊 [1,2]；列池 Mon₁={ca,cb}、Mon₂={a,b,ca,cb}、Tue={c,ab,b}，ca/cb 成本 1、单店与 ab 成本 0 ⇒ GLOP 实测 v1 LP=1、v2 LP=2。该人工矩阵仅用于数学正确性测试。
- **整数可行集等价（前提：v1 使用与 v2 相同的合同合法列域）**：v1 可行 ⇒ v2 可行（y 由链接行 (B) 唯一确定；(C)(D) 由 v1 的 (4)(3) 与整数性保证）；v2 可行 ⇒ v1 可行（(B) 还原 (3)，(C) + 整数性给出 (4)）。未经合法域处理的 v1 不在本命题范围内。
- **z 整分性传导**：x 整分 ⇒ y 由 (B) 唯一确定且整分 ⇒ (C) 强制被访日期全部落在 z=1 的星期几 ⇒ (D) 保证频次 ⇒ 合同精确满足。
- "更紧"只描述界的质量，不自动表示求解时间与总体算力无取舍——实测记录进对照报告。

### 3.5 合法域与池过滤的关系

- v2 下 SP 正确性不再依赖 `_contract_pool_filter`（非法列因 y 上界 0 而不可选）。池过滤保留为**引擎侧卫生**，不再是正确性依赖。
- 附带收益：评估层池截断不再有"过滤饿死店"的正确性风险（饿死如实表现为 INFEASIBLE）。

### 3.6 bp 接入（P0-2 合并交付，R3 资格条件全集化）

- 节点 LP = v2 master + 分支行：`y_cd = 1`（forced）或 `y_cd = 0`（forbidden）——分支直接落在 y 一等变量上。
- **`node_valid_lb` 资格条件（全部满足才赋值，否则 UNKNOWN）**：
  1. 节点 LP 求解状态 = OPTIMAL（FEASIBLE 不够）；
  2. 定价使用的对偶、池成本、节点状态属**同一求解快照**；
  3. 全部日期完整定价完成（逐日 OPTIMAL，最小 rc 在声明容差内非负）；
  4. 可行性恢复引入的人工/临时变量已清零或已从模型移除。
- **范围规则**：根节点的有效 LP 界在搜索未完成时也可作全局下界使用；单个子节点的有效界**不**具备全问题范围；全树耗尽 + 全节点证毕才得 `certified_global_lb`。不得用"全树证明后升级"代替上述范围与聚合规则。
- **受限池不可行 ≠ 业务/完整节点不可行**：缺列、恢复失败、预算截止均保持未证状态。
- **回滚纪律**：任何版本（含回滚到 v1 形态）都必须满足同一资格条件；切版本不得重新启用未经证明的界剪枝或全局证书。

### 3.7 字段名（R7 对齐）

对外（协议 `research_matrix/v1` §8.2 为准）：`rmp_lp_value`（附 LP 状态）、`pool_gap_pct`、`certified_global_lb`（无有效全局界时为 `null`）、`global_gap_pct`。`node_valid_lb` 为**内部字段**（带节点身份），不入协议。实现与文档不再使用 `pool_lp_value` / `certified_lb` 等未登记变体名。

## 4. 兼容与回滚

- VisitModel 新增 `sp_solve_lp_v2 / sp_solve_ip_v2`（或 `formulation="linkage"` 参数），v1 保留过渡期；母仓 `column_generate` / `branch_and_price` 加 `formulation` 开关，默认 v1，验证后切 v2 并废弃 v1。
- 回滚 = 开关切回 v1，单 commit revert；**回滚不重新启用任何未证下界的剪枝/证书**（v1/v2 同受 §3.6 资格条件约束）。
- 姊妹改动：`price_columns` 增加 β 奖励入参（或 v2 专用定价入口）；母仓 dedupe/池过滤降级为卫生措施（行为不变）。

## 5. 测试守卫（按评审建议重建）

1. **rc 一致性**：每条池内列手算 rc 与求解器 `reduced_cost()` 一致；覆盖上界态、下界态、退化与符号反例（R1 的 β=−3 迷你例入测）。
2. **全列枚举真值**：微型实例全列枚举——CG 最终 LP 值 == 完整 master LP 最优值；精确定价最小 rc == 枚举最小 rc。（替代 v0.2 的"池 IP == RMP 整数最优"同义反复测试。）
3. **同冻结核等价**：冻结同一合法列池、同一成本与数值尺度，v1/v2 IP 均证完时比较最优值与可行解投影。
4. **分类状态**：零频次星期几（R2 反例入测）、非法相位列、空合法域、过滤后缺覆盖——分别走明确不可行/明确状态，不得静默。
5. **证书门控**：非最优 LP、未完定价、受限池不可行、预算截止、回滚路径——均不得生成错误证书；`certified_global_lb=null` 正确落盘。
6. **端到端对照（分报告，非等价闸）**：10 线跑 v1/v2 双形态，报告质量、耗时、列池规模、证完率差异；不把不同列池的结果相等当作模型正确性证明。

## 6. 风险

| 风险 | 缓解 |
