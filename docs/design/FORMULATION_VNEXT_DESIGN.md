# VisitModel Formulation vNext 设计：固定 (店,日期) 行空间的 Contract-SP 重构

> **状态**：草稿 v0.1 · 2026-09-07（待评审；通过后转实施计划）
> **缘起**：外部评审 P0-1（2026-09-07）——现行 Contract-SP 主问题的 `x_r ≤ z_{c,wd(r)}` 绑定行是**列特定行**：新增一条候选列会同时新增若干绑定行，行空间不固定；且列生成（CG）的 rc 公式未计入绑定行对偶。二者叠加 ⇒ 现行"LP → 按对偶定价 → 收敛"不是标准的固定行空间列生成（CG），CG/B&P 的"收敛/下界/证书"数学依据有洞。
> **归属**：`VisitModel` 仓 `visitmodel.sp.formulation` + `visitmodel.sp.pricing`（设计文档暂存母仓 `docs/design/`，剥离后随 VisitModel 走）。
> **同批交付**：P0-2（bp 下界语义：`rmp_lp_value` / `node_valid_lb` 分离 + 剪枝门控）在本重构之上自然完成，合并一个实施计划。

---

## 1. 背景

### 1.1 现行 master（v1，`formulation.py`）

```
min  Σ_r km_r x_r
s.t. (1) Σ_{r∈R_d} x_r = 1                 ∀d          对偶 π_d
     (2) Σ_w z_cw = 1                       ∀c
     (3) Σ_{r∋c} x_r = Σ_w f_cw z_cw        ∀c          对偶 μ_c
     (4) x_r ≤ z_{c,wd(r)}                  ∀r, ∀c∈r    ← 列特定行（问题所在）
     x ∈ [0,1], z ∈ [0,1]
```

### 1.2 两个数学缺口（评审核验属实）

1. **行空间不固定**：约束 (4) 对每条池内列、每家列内店各一条——新列进来同时新增 |route| 条行。经典列生成的前提是"对偶行空间固定、列空间动态扩展"；行随列增长后，"LP → 对偶 → 定价 → 收敛"不再是标准的 fixed-row CG。
2. **rc 不闭合**：现行定价 `rc(r@d) = km_r − Σ_{c∈r} μ_c − π_d` 未计入 (4) 的对偶贡献。按标准定义 rc 必须 = c_j − (对偶转置)·(该列在**所有**非零系数约束行上的系数列)。两者放在一起，"定价器找不到负 rc 列"既不证明收敛，据此得到的"下界"也不可靠。

### 1.3 影响面

| 受影响 | 影响 | 不受影响 |
|---|---|---|
| `sp_solve_lp`（CG 收敛语义与下界有效性） | CG 提前终止/界语义打折 | **SP-IP 终闸（CP-SAT）解的正确性**——全行显式建模、精确求解，历史 km 数字（−13.03% 等）有效 |
| `price_columns`（rc 方向） | 定价漏列/误列 | 各引擎候选生成（列来源合法性与本重构正交） |
| `branch_and_price`（节点 LP、分支、剪枝、证书） | 下界与剪枝安全性（P0-2） | 引擎接口契约（LineData/D/AlgoResult） |

## 2. 目标与非目标

**目标**：
- G1 固定行空间：新列只给**既有行**加系数，CG 回归标准 fixed-row 形态。
- G2 合法域内生化：合同/相位合法性由变量域表达（非法 (店,日期) 的 y 上界固定为 0），不再依赖池预过滤保证正确性。
- G3 定价 rc 与 master 严格闭合（含全部对偶贡献），CG 收敛判据恢复数学含义。
- G4 bp 分支直接落在 y 空间；`rmp_lp_value` / `node_valid_lb` 分离，剪枝门控 `pricing_proven`（P0-2）。
- G5 与 v1 的解集等价性有测试证明（微型实例全枚举 + 10 线并行对照）。

**非目标**：不实现 ESPPRC 精确定价本体（另立计划）；不改引擎输入输出契约；不回填历史实验。

## 3. v2 数学设计

### 3.1 变量

| 变量 | 域 | 说明 |
|---|---|---|
| `x_r` | [0,1]（LP）/ {0,1}（IP） | 候选列选择，r ∈ 池 |
| `y_cd` | [0,1]（LP）/ {0,1}（IP）；**UB=0 若 (c,d) 合同非法** | 店-日访问指示：店 c 在日期 d 被访。全 (c,d) 网格创建，非法格用上界 0 封死 |
| `z_cw` | [0,1] | 星期几选择器（同 v1） |

### 3.2 行（全部固定，定义在实例域上，与池无关）

```
(A) 日期覆盖      Σ_{r∈R_d} x_r = 1                 ∀d          对偶 π_d
(B) 链接定义      y_cd − Σ_{r∈R_d: c∈r} x_r = 0      ∀(c,d)      对偶 β_cd
(C) 星期几绑定    y_cd ≤ z_{c,wd(d)}                 ∀(c,d)      对偶 γ_cd
(D) 合同频次      Σ_d y_cd = Σ_w f_cw · z_cw         ∀c          对偶 μ_c
(E) 唯一星期几    Σ_w z_cw = 1                       ∀c
(F) 合法域        y_cd ∈ [0, UB_cd],  UB_cd = 0 若 (c,d) 非法
```

新列 r 进入时只做一件事：往 (A)(B) 的**既有行**上加系数。行数 = |D| + |C|·|D| + |C|·|D| + |C| + |C|，恒定。

### 3.3 定价（CG）

```
rc(r@d) = km_r − π_d − Σ_{c∈r} β_cd
```

- β_cd 是 (c,d) 链接行对偶——**逐 (店,日期) 的访问奖励**，比 v1 的 μ_c（跨日共享）表达力更强，定价信号更准。
- 定价子问题结构不变：当日合法店集上"选 ≤max_daily、≥min_daily 个店，最大化 Σβ − 路径长"——现有贪心启发式与 CP-SAT 奖收集兜底都可平移，只是奖励从 μ_c 换成 β_cd。
- 收敛判据恢复标准含义：全日期精确证明无负 rc 列 ⇒ LP 为该节点完整主问题的最优 ⇒ 可作有效下界。

### 3.4 与 v1 的等价性（要点）

- **可行集投影等价**：x ≥ 0 时，"每列 x_r ≤ z" ⟺ "聚合 Σ_{r∈R_d∋c} x_r ≤ z"（个体和 ≤ 和 ≤ z ⇒ 个体 ≤ z；反之聚合约束由个体相加即得）。故 (B)+(C) 的可行投影与 v1 的 (3)+(4) 相同；整数域同理。⇒ v1 与 v2 的可行解集一一对应（y 由链接行唯一确定）。
- **z 整分性传导**（v1 论证在 v2 依然成立且更严谨）：x 整分 ⇒ y 由 (B) 唯一确定且整分 ⇒ (C) 强制被访日期全部落在 z=1 的星期几 ⇒ (D) 保证频次 ⇒ 合同精确满足。
- **LP 界对比**：v2 的 (C) 是聚合式，v1 的 (4) 是逐列式——逐列式更强（LP 界更高）。**取舍**：v2 接受 LP 界略微放松，换取固定行空间的标准 CG 与闭合的 rc；v1 的强 LP 界在启发式定价下本来就不可靠（P0-2），净收益为正。测试中将量化两者 LP 界差。

### 3.5 合法域与池过滤的关系

- v2 下 SP 正确性不再依赖 `_contract_pool_filter`（非法列因 y 上界 0 而不可行）。池过滤保留为**引擎侧卫生**（减少无效列），不再是正确性依赖。
- 附带收益：`dedupe_pool`/池截断等评估层操作不再有"过滤饿死店"的正确性风险（饿死在 v2 中如实表现为 INFEASIBLE）。

### 3.6 bp 接入（P0-2 合并交付）

- 节点 LP = v2 master + 分支行：`y_cd = 1`（forced）或 `y_cd = 0`（forbidden）——分支直接落在一等变量上，比 v1 的 forced 覆盖行更干净。
- **下界门控**：节点求解返回 `{rmp_lp_value, node_valid_lb}`；`node_valid_lb = rmp_lp_value` 当且仅当该节点精确定价证明无负 rc 列，否则 `node_valid_lb = UNKNOWN`。剪枝只允许用 `node_valid_lb`；`rmp_lp_value` 仅作观测。
- 定价 rc 换 β_cd 后，现有"启发式贪心 + CP-SAT 奖收集兜底"结构平移。

## 4. 兼容与回滚

- VisitModel 新增 `sp_solve_lp_v2 / sp_solve_ip_v2`（或 `formulation="linkage"` 参数），v1 保留一个过渡期；母仓 `sp_matheuristic.column_generate` / `branch_and_price` 加 `formulation` 开关，默认 v1，验证后切 v2 并废弃 v1。
- 回滚 = 开关切回 v1，单 commit revert。
- 姊妹改动：`price_columns` 增加 β 奖励入参；母仓 dedupe/池过滤降级为卫生措施（行为不变）。

## 5. 测试守卫

1. **全枚举等价**：微型实例（≤6 店 ≤4 日）全列枚举，v1 IP 与 v2 IP 最优值相等；可行解集投影相等。
2. **LP 界对照**：同池下 |v1_LP − v2_LP| 量化记录（预期 v2 ≥ v1，差距即逐列绑定式的贡献）。
3. **CG 收敛一致**：v2 CG 收敛后的池 IP == 收敛时 RMP 的整数最优（fixed-row 不变量）。
4. **非法域守卫**：含非法 (c,d) 的列在 v2 IP 中不可被选中（UB=0 生效）。
5. **10 线并行对照**：v2 流水线 km 与 v1 流水线 km 逐线相等（±容差），`contract_violations=0`。
6. **bp 门控**：`pricing_proven=False` 时 `node_valid_lb=UNKNOWN` 且不参与剪枝（测试钉住）。

## 6. 风险

| 风险 | 缓解 |

| v2 LP 界放松掩盖真实 gap 改进 | 测试 2 量化差值；界收紧的另一路径（逐列式保留 + 修正 rc）在设计中说明为何不取（行空间不固定的根因未除） |
| 引擎适配回归 | 黄金值测试（R2ALNS 300 迭代 km/md5）不涉 formulation，不受影响；SP 侧对照测试覆盖 |
