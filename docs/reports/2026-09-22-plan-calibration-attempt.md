# 计划校准尝试与失败记录 · 2026-09-22

**目标（老板口径）**：让计划更贴近业务实际，而不是找空白区域。

## 试过的方法（`experiments/plan_calibrator.py`）
用每人 W1–W2 的**实际到访**重编 W3–W4 计划 P1（门店池=实际在跑的店；频次=训练期次数×2；星期=训练期该店主力星期；日容量=训练期同星期日均×1.1），
与现行计划 P0 对 W3–W4 实际到访评分：

| 指标（中位，558 线） | 现行 P0 | 校准 P1 |
|---|---|---|
| 同店同日命中 | **86.0%** | 4.2% |
| 星期命中 | 86.0% | 9.5% |
| 门店覆盖 | 86.8% | 19.0% |

分型看：照做型 P0 98.1% / P1 6.6%；区块内欠访型 P0 61.2% / P1 2.6%。

## 失败原因（重要结论）
1. **用半个月的观察去"重排具体日期"，必然丢掉现行计划里已有的日期信息**——计划在"哪天去哪家"上已经贴着实际（照做型 98%）。
2. 因此"贴近实际"**不等于**重排日期；**正确落点是改计划里执行不到的成分**：
   - 从未执行的门店/块 → 降频或移出计划；
   - 超产能的块 → 减量（月访 2 次→1 次），使计划可完成；
   - 长期没开工的块 → 改派或移出。
3. 差异来源是"量/块"而非"日期"：照做型 P0 同日 98.1%，而区块内欠访/缺块/大面积没开工三类只有 34–61%。

## 下一步（频率与范围校准，不重排日期）
对 `output/rep_behavior/dossier.json` 的七类人分别算：计划中"零执行门店"占比、块内实际完成量 vs 计划量，
产出**逐人计划侧改动建议**（降频/移出/改派），并估算改动后可完成度提升。

## 追加：区块定义的文献依据与对撞结果（2026-09-22 晚）

**质疑**：分几块有逻辑吗？有论文吗？

**文献（已核实）**
- Zoltners & Sinha (1983) *Sales Territory Alignment: A Review and Model*, **Management Science 29(11):1237-1256** — 区域划分三判据：**连通性 / 紧凑性 / 工作量平衡**。
- Duque, Ramos, Suriñach (2007) *Supervised Regionalization Methods: A Survey*, **Int. Regional Science Review 30(3):195-220** — 本方法属 regionalization（连通约束聚类），**结果对连通图与阈值高度敏感**。
- Guo (2008) **REDCAP**（MST 约束的凝聚聚类 + 平衡再分）— 规范化的区域构建流程。

**两条口径对撞（582 线）**

| 判据 | 旧口径：纯几何 H3 连通 | **新口径：服务日 × H3 连通** |
|---|---|---|
| 块数中位 | 2（把一天的量混成一大块） | **7**（23% 的线正好 5 块＝一天一块） |
| 平衡 CV（越低越好） | 0.960 | **0.598** |
| 紧凑度中位 | — | 0.479 |
| 业务含义 | 无 | 块 = 系统指派的"服务日"下的连续商圈 |

**关键发现（计划不贴实际的量化缺口）**
- **实际主力星期 == 服务日：中位 66.9%、均值 59.0%**；只有 23% 的线 ≥90%。
- 即**约 1/3 门店：系统让它某天去，业务实际在别的天去**。改法就在数据里：`服务日 := 实际主力星期`（保持连通/相位/频次约束）。
