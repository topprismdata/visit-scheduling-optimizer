## 2. 核心科学问题（Q1–Q5）全景回答

### Q1: 劣质经验注入是否能被可靠免疫？
**能，100% 阻断**。
- `MDVL (MP-G1/MP-G2)` 在记忆入库前严格执行成效门限与不变量扫描，任何导致商业亏损或违反物理/法律不变量的“错误经验”被确定性标记为 `REJECTED`，杜绝企业 AI 学习“有毒经验”。

### Q2: 环境发生漂移时，记忆是否会导致过约束与机会损失？
**不会，具备自动失效与淘汰机制**。
- `context.invalidation_conditions` 在运行时持续监听环境变化，一旦前提条件消失（如客户取消偏好），过时记忆自动降级为 `DEPRECATED`，主动释放数学模型的解空间。

### Q3: 相互冲突的经验如何裁决？
**基于“上下文特异性（Context Specificity）> 置信度（Confidence）”规则确定性仲裁**。
- 具体情景规则（如预算紧缺情景）优先于宏观通用规则生效，确保决策编译器始终获得一致、无歧义的语义指导。

### Q4: 跨领域迁移是否会产生错误泛化？
**不会，由 MP-G5 严格防卫**。
- 任何试图脱离原商业上下文的无边界迁移，均被 `MP-G5 (Cross-Domain Transfer Gate)` 拦截在领域边界之内。

### Q5: 记忆规模增长是否会引起约束爆炸？
**不会，编译器具备同类项合并能力**。
- 注入 50+ 记忆条目后，编译器前端自动将其归类合并为参数校准与偏好强化两类语义 Patch，未发生约束冗余爆炸。
