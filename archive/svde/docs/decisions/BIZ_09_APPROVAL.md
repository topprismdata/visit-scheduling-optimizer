## 1. 业务问题

哪些排班方案需主管书面批准？哪些系统自动放行？哪些需上报区经理？

## 2. 选定规则 (rule)

| 方案类型 | 审批层级 |
|---|---|
| 全自动排班（无约束违反） | 系统自动放行 |
| 含 1-2 个 WARNING 级违反 | 主管书面确认（系统外）后放行 |
| 含 ≥3 个 WARNING 或 1 个 CRITICAL_INCIDENT | 区域经理书面审批 + 销售运营经理会签 |
| 涉及 Key 店 0 次拜访 | **必须** 销售副总书面审批 |
| 涉及 ≥10 家店改派 | 区域经理 + 销售运营经理双签 |

## 3. 适用范围 (scope)

所有 MVP 输出的 CandidatePlan。

## 4. 生效时间 (effective_time)

2026-09-01 生效。

## 5. 责任人 (owner)

业务方: 销售运营经理 + HR + 销售副总。

## 6. 例外条件 (exceptions)

- 重大促销期间: 阈值放宽至 ≥5 WARNING 才需区域经理审批
- 紧急客户需求: 主管可在 4 小时内补批
- 培训期代表: 主管直接代批

## 7. 违反处理 (violation_handling)

- **WARNING**: 未经审批直接下发
- **CRITICAL_INCIDENT**: 涉及 Key 店 0 次未上报副总
- 系统记录未审批事件，需事后追溯
