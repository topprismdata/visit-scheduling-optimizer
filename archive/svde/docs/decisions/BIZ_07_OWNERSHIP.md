## 1. 业务问题

两家代表同时拜访同一家店（"撞单"），如何判定归属？优先级规则是什么？

## 2. 选定规则 (rule)

| 场景 | 归属优先级 |
|---|---|
| 1. 门店主代表已分配 + 撞单 | 主代表优先（撞单方记录协作拜访） |
| 2. 同一代表撞自身多任务 | 时间早的拜访有效 |
| 3. 跨大区临时支援 | 临时支援方拜访，主代表事后知会 |
| 4. 客户主动指定代表 | 客户指定优先 |

## 3. 适用范围 (scope)

所有 246 家门店的所有撞单场景。

## 4. 生效时间 (effective_time)

2026-09-01 生效。

## 5. 责任人 (owner)

业务方: 销售运营经理。

## 6. 例外条件 (exceptions)

- 主管跨区抽检: 例外（不视为撞单）
- 培训期陪同拜访: 例外（受训代表不占归属）
- 临时紧急协同: 例外（双方均分业绩）

## 7. 违反处理 (violation_handling)

- **WARNING**: 撞单未在 24 小时内报备
- **CRITICAL_INCIDENT**: 撞单造成客户投诉或订单错记
